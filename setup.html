连接文献库，开始每日推荐

原版推荐按你在设置页填写的关键词和作者置前；Zotero 推荐根据云端文献摘要的相似度排序。两种方式使用同一批每日论文。

1. 准备三个凭据

在你的 GitHub 仓库中打开 Settings → Secrets and variables → Actions，将以下三项添加为 Repository secrets。密钥保存在这里，无需输入网页。

  • ZOTERO_ID：Zotero 的数字用户 ID，可在 Zotero API 设置查看。
  • ZOTERO_KEY：同一页面创建的密钥，只需勾选个人文献库的读取权限。请先同步 Zotero 文献。
  • DEEPSEEK_API_KEY：在 DeepSeek 平台创建的 API 密钥。

2. 运行第一次更新

打开仓库 Actions，选择 Daily papers · Zotero + DeepSeek，点击 Run workflow。任务完成后，本页会显示论文日期、中文概括和 Zotero 分数。此后每日自动运行，也可手动更新。

3. 设置自己的关键词

在偏好设置里添加关键词和作者。这些偏好保存在当前浏览器；它们影响原版推荐的顺序，不会改变后台每天生成中文概括的范围。

默认范围与费用控制

抓取 cs.CV、cs.LG、cs.AI、cs.CL 四类，Zotero 使用个人文献库中带摘要的会议、期刊和预印本文献。每天最多为 Zotero 排名前 50 篇尝试生成中文概括；其余保留原始摘要。成功结果会缓存，失败时保留原摘要。相关性分数用于排序，不代表百分比或推荐准确率。

网页公开展示新论文及推荐分数。后台读取的 Zotero 条目和向量不会随网页发布。

分类、模型和篇数可在仓库 Variables 中修改。详细部署与恢复说明见仓库 README。
