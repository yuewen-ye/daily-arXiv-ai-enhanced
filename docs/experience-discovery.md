## 第二次核实：受控执行

2026-10-29，使用 Node 直接执行当前 recommendations.js，以及在隔离环境中执行当前 app.js。结果：

- 两篇合成论文，搜索 `Diffusion` 得到 1 个命中、仍返回 2 篇；搜索不存在的 `no-such-topic` 得到 0 个命中、仍返回 2 篇。
- 对归档列表读取分别模拟 HTTP 503、网络异常、HTTP 200 空列表，执行实际 DOMContentLoaded 回调和 fetchAvailableDates；三种情况均显示“暂无归档”并建议完成 Zotero 与 DeepSeek 配置。

受控环境替代了网络与最小页面节点，并跳过外围控件初始化；没有调用模型、Zotero 或付费 API。这证明相关 JavaScript 分支的执行结果，不能证明真实浏览器布局、触控体验或线上服务当前状态。

该复现证明了修改前的错误反馈路径。用户授权后，已将读取失败与真实空归档分开，并验证重试可恢复。

## 最终改动

- 搜索保留命中置前的默认规则，显示匹配数、总数与当前显示数；增加“仅看匹配”和清空操作。零命中有专门提示。
- 搜索不再逐个开关偏好标签并多次重建列表；保留偏好选择，搜索时文本匹配优先，清空后按偏好排列。
- 归档列表读取失败显示独立错误与重试；只有成功返回空列表才提示配置。单日和多日读取统一检查 HTTP 状态，读取含响应体在 15 秒后超时。
- 多日读取最多并发四天，显示进度；按论文 ID 去重，保留较新日期记录；部分失败保留成功结果，重试只补读失败日期。旧请求不能覆盖新选择。
- 日历只启用真实归档日期，隐藏日历不再暴露不可见控件；重新打开范围选择时保留合法起止日期，避免把日期范围说明当成单日解析。
- 偏好以完整文本忽略大小写判重，允许有前缀关系的不同关键词或作者。保存与复制使用原始标签值，保留值中的 × 等字符。
- 更新 README、GLOSSARY 和持续集成检查，CodeGraph 本地索引加入忽略列表。

本轮为可逆的交互改进，没有产生需要 ADR 的长期架构取舍。

## 2026-11-01：区分最近更新与归档批次

用户同意将北京时间更新时刻与 UTC 归档日期分开展示。

- 每日任务在归档内容写入后记录带时区的 `updated_at`，表示该批数据处理完成时间。
